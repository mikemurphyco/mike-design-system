02 · Brand personality

The rubric

Every design decision passes one test: does it feel clean, calm, technical, warm, lightly handmade, and never corporate? If yes, ship it. If no, cut it.

Voice

I speak in first person. The reader is "you". Never "our team", never startup-speak, never guru energy.

Tone

Calm, clear, practical, encouraging. The guy who already wrestled with the confusing part and is showing you the shortcut.

Texture

Short sentences. Contractions. Specific tools and workflows. Honest about friction. Occasionally funny, never loud.

04 · Color

Seven tokens. No alternatives.

Brand layer → semantic layer
--mm-cream #E8E2D9

Page background. Default surface. Never pure white.

--mm-chalk #FAF7F2

Brightest surface. Cards, modals, code-block frames.

--mm-navy #0D1B2A

Body text, borders, the offset shadow stamp. Never black.

--mm-orange #E8622A

Primary action / CTA accent.

--mm-orange-deep #C94E1A

Hover / pressed state for orange.

--mm-yellow #F5C842

"Tape" inside the AI Handyman badge. Reserved for orange surfaces.

--mm-teal #1ECEBE

"AI pop." Cursors, code accents, live status. One use per screen.

Pairing rule cream + navy ink

Default text/surface relationship across the system.
